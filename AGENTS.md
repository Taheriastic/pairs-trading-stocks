# Project guidance

This repository is a public-facing finance research case study. Read `METHODOLOGY.md` and `DATA_SOURCES.md` before changing calculations or sources. Treat historical research prices as distinct from executable quotes. Never claim a predictive trading edge from the small sample. Explain the fiscal period and filing source for reported financial values. Keep Azure status truthful: code integration, local testing, and deployed service are different states. Before changing public copy or résumé claims, verify them against the current build and deployed services.
