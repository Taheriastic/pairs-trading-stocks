# 📓 Research Notebooks

This directory contains research and exploratory notebooks for the **Coca-Cola (KO) vs. PepsiCo (PEP)** pairs trading project.

## Available Notebooks

- `01_ko_pep_cointegration.ipynb`: Exploratory data analysis, unit root tests (ADF), Engle-Granger two-step cointegration estimation, spread dynamics, and parameter calibration.
- `02_backtest_and_sensitivities.ipynb`: Detailed backtest walkthrough, parameter sweeps ($k_{\text{entry}}, k_{\text{exit}}, w$), and transaction friction curves.

## Running the Notebooks
```bash
jupyter notebook notebooks/
```
